# DJ Vault - Epic Features Guide

## 🎯 Overview

DJ Vault is the ultimate music discovery and curation platform for exploring rock, metal, grunge, and punk across 6 decades. Built for families to share music memories and discover new favorites together.

## ✨ Core Features

### 🎵 Curated Music Library

- **21 Seed Tracks** - Hand-picked classics from Metallica, Nirvana, Pearl Jam, Tool, Ghost, Tesla, and more
- **Smart BPM Detection** - Every track shows tempo (beats per minute) for mixing
- **Visual Waveforms** - Unique waveform visualization for each track
- **Vote System** - Reddit-style upvote/downvote to build your favorites
- **Genre & Era Filtering** - Browse by Metal, Grunge, Punk, and more across 70s-20s

### 🔍 Discovery Engine

#### Artist Relationship Database
- **30+ Artist Mappings** with curated similarity data
- **Tesla** → Def Leppard, Whitesnake, Warrant, Cinderella, Great White
- **Nirvana** → Pearl Jam, Soundgarden, Alice in Chains, Foo Fighters
- **Metallica** → Megadeth, Slayer, Anthrax, Testament
- And many more relationships!

#### Smart Similarity Algorithm
Finds related tracks based on:
- Artist relationships (+35 points for very similar artists)
- Genre matching (including subgenres like Hair Metal, Thrash Metal)
- Era proximity (same decade or adjacent)
- BPM compatibility
- Note keywords (energy, mood, vibe)

#### Discovery Panel
- **"If you like [artist], try..."** suggestions for current track
- **12+ recommended artists** based on your entire library
- One-click YouTube search for any artist
- Right-click to copy search query

### 📻 Radio Mode (NEW!)

**Endless discovery playback** - Never run out of music

- Click "Start Radio" on any playing track
- Automatically queues similar tracks as you listen
- Shows tracks discovered and queue depth
- Creates a personalized, endless music journey
- Perfect for parties or background listening

### 💾 Playlists & Memories

#### Save with Meaning
- **Named playlists** - "Dad's Favorites", "Mom's Classic Rock"
- **Personal dedications** - "In loving memory of..." messages
- **Auto-saved** - Everything persists to your browser automatically
- **Creation dates** - Remember when you made each set

#### Backup & Share
- **Backup button** - Download playlists as JSON file
- **Restore from backup** - Import playlists on any device
- **Share links** - Anyone can play your set instantly, no login
- **Portable** - Take your playlists anywhere

### 🎬 Set Mode

**Fullscreen experience with live visualizer**

- Press `f` to enter Set Mode
- **Live audio visualizer** - Animated frequency bars react to music
- **Big now-playing display** - See track info clearly
- **Up-next queue** - Know what's coming
- **BPM display** - See tempo in real-time
- Perfect for:
  - Parties and gatherings
  - Memorial events
  - Personal listening sessions
  - Showcasing your music taste

### 📊 Music Profile

**Understand your taste**

- **Top Genres** - Visual breakdown with percentages
- **Favorite Eras** - See which decades you love
- **Average BPM** - Your preferred tempo
- **Most Collected Artists** - Top 5 artists in your vault
- **Your Favorites** - Highest voted tracks

### ⌨️ Keyboard Power User Features

- `/` - Focus search
- `j/k` or `↓/↑` - Navigate tracks
- `Enter` - Play selected track
- `u/d` - Upvote/downvote
- `q` - Queue selected track
- `s` - Find similar tracks
- `n/p` - Next/previous track
- `f` - Toggle Set Mode
- `a` - Add new track
- `Esc` - Close panels/exit Set Mode
- `?` - Show all shortcuts
